# Utility Mod (Fabric 1.16.5)

ClickGUI на Right Shift: Полёт, Ускорение, Автоспринт, Step, Фуллбрайт, Зум + HUD.

## Сборка
Нужны JDK 17 и интернет.

    gradlew build        (Windows)
    ./gradlew build      (Linux/Mac)

Готовый jar: build/libs/utilitymod-1.0.0.jar (НЕ -sources.jar).
Положи его в папку mods вместе с Fabric Loader и Fabric API 0.42.0+1.16.
